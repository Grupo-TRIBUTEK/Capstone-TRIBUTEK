# Avance - Autenticación

Se implementó la primera parte del sistema de autenticación de TRIBUTEK, incorporando la búsqueda de usuarios, validación del estado de la cuenta y verificación segura de contraseñas mediante Argon2.

## 1. Implementación de autenticación

El módulo `Auth` actualmente permite recibir las credenciales mediante:

```text
POST /auth/login
```

El proceso implementado en `auth.service.ts` realiza:

1. Buscar al usuario mediante `nombreUsuario`.
2. Comprobar que el usuario exista.
3. Comprobar que la cuenta se encuentre activa.
4. Verificar la contraseña utilizando Argon2.
5. Devolver los datos básicos del usuario si las credenciales son válidas.

## 2. Argon2

Se instaló la dependencia:

```powershell
npm install argon2
```

La contraseña ingresada durante el login se compara con el `passwordHash` almacenado en PostgreSQL mediante:

```ts
const passwordValida = await argon2.verify(
  usuario.passwordHash,
  loginDto.password,
);
```

Si la contraseña no coincide, se devuelve:

```ts
throw new UnauthorizedException(
  'Usuario o contraseña incorrectos',
);
```

Argon2 no desencripta la contraseña almacenada. Comprueba si la contraseña ingresada corresponde al hash guardado.

## 3. Roles

Se crearon los primeros roles del sistema:

| ID | Nombre  | Descripción                                      |
| -: | ------- | ------------------------------------------------ |
|  1 | ADMIN   | Usuario con permisos administrativos del sistema |
|  2 | CLIENTE | Usuario asociado a un cliente de TRIBUTEK        |

## 4. Usuario de prueba

Se creó un usuario de prueba asociado al rol `ADMIN`.

```text
Nombre: Administrador de Prueba
Usuario: admin
Contraseña de prueba: 123456
Rol: ADMIN
Activo: true
```

La contraseña no se almacena como texto plano. Se generó un hash mediante Argon2 y este fue almacenado en `password_hash`.

Para generar temporalmente el hash se utilizó un script:

```text
backend/scripts/generate-password.mjs
```

Este archivo se utiliza únicamente como herramienta de prueba y puede eliminarse posteriormente.
